# communactive (커뮤넥티브)

디시인사이드 · 아카라이브 · 루리웹 같은 커뮤니티 사이트. 게시판 하나하나를 **커뮤니**라고 부른다.

## 기능
- **커뮤니**: 누구나 만들 수 있는 게시판 (`/c/<주소>`). 맨 위에 인기글(최근 7일, 추천 3개 이상)이 뜬다.
- **홈**: 모든 커뮤니를 합쳐서 **실시간(최근 3시간 동안 받은 추천) / 일간 / 주간 베스트**를 보여준다.
- **포인트**: 글 작성 +200P, 댓글 +50P. 글이나 댓글을 지우면 받은 포인트를 회수한다.
- **커뮤콘**: 유저가 이미지를 올려 직접 만들고 가격을 정한다. 다른 유저는 포인트로 사서 댓글에 쓴다.
- **로그인**: 구글 / 네이버 / 페이스북 소셜 로그인 → 닉네임 정하고 가입. 마이페이지에서 여러 계정을 연동할 수 있다.

## 실행
```powershell
.\.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # 처음 한 번만. 그다음 값 채우기
python seed.py              # 샘플 데이터 (선택)
python app.py               # http://localhost:5000
```

## 소셜 로그인 설정
`.env.example`에 각 개발자 콘솔 주소와 등록할 콜백 URL이 적혀 있다.
키를 넣기 전까지는 `DEV_LOGIN=1`로 켜지는 **개발용 로그인**으로 테스트할 수 있다. 운영할 때는 반드시 `DEV_LOGIN=0`으로 끄자.

## 파일 구조
| 파일 | 역할 |
|---|---|
| `app.py` | 앱 생성, 블루프린트 등록 |
| `config.py` | 설정 (포인트 액수, 인기글 기준 등) |
| `models.py` | DB 모델 |
| `auth.py` | 소셜 로그인 / 회원가입 / 계정 연동 |
| `board.py` | 커뮤니, 글, 댓글, 추천 |
| `cons.py` | 커뮤콘 상점 / 만들기 / 구매 |
| `main.py` | 홈 (베스트), 마이페이지 |
| `utils.py` | 포인트 지급, 베스트 집계, CSRF, 템플릿 필터 |
